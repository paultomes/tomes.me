# tomes.me homepage explorations

These are self-contained, local-only interaction studies. They do not alter the
production `index.html`, deployment configuration, or linked applications.

Run from the repository root:

```sh
python3 -m http.server 4173
```

Then open:

- `/concepts/ring/`
- `/concepts/aperture/`
- `/concepts/threshold/`

Each study is keyboard-operable: `Enter`/`Space` opens the navigation, `Escape`
closes it, and focus moves into the first destination. All motion is suppressed
for `prefers-reduced-motion`.
