# Flaine 2027 local studies

Serve the repository root and open one of the following paths:

- `/concepts/snow/summit-log/` — the refined, information-forward direction.
- `/concepts/snow/contour/` — the most graphic, expedition-style direction.
- `/concepts/snow/field-notes/` — the most editorial, tactile direction.
- `/concepts/snow/summit-contour/` — the Summit Log hero combined with the
  simpler Contour report and resource layout.

Each study reads destination data, dates, protected Sheet URL and resource links
from `ski-trip.config.js`. It fetches the same Open-Meteo model forecast at
1,600 m and 2,500 m, labels the result as modelled data, and gracefully directs
people to the official report if unavailable. The hero is original generated
concept art, not a claim about a literal Flaine view or a production asset.
